# Training Plan: Bench Rehab Bridge → 1RM Test

## Overview

Revision of the original 8-week strength plan. The first block (weeks 1–8) ran cleanly and ended with a deload in week 9. The 1RM test scheduled for week 10 is **deferred** because of a lingering twinge in Tim's injured hand when benching above 50 kg.

This revision is a **6-week bridge block (weeks 10–15)** built around two goals:

1. Re-expose the hand to bench loads ≥ 50 kg gradually, watching for symptoms — no grinding, no surprise jumps
2. Keep the rest of the body progressing normally so the layoff doesn't bleed into squat / pull / posterior-chain gains

**Bench progression rule for this block**: load is capped just below the symptom threshold. Each session adds 2.5 kg only if the previous session's top set was clean *and pain-free*. If any twinge appears, hold the load and add a set (volume-up) instead. The 1RM (or rep-out proxy) test happens once Tim has banked **two consecutive clean sessions at 50 kg**, plus one at 52.5 kg.

**Other lifts**: standard linear progression resumes. Squat returns to pre-deload weight and pushes into new territory. Pulling, hip-hinge, and core work continue as before. Hip thrusts have been skipped 3+ times — make them non-negotiable.

**Schedule**: still 2 days/week, Tuesday and Friday. Day 1 = Bench Focus, Day 2 = Squat & Pull Focus. Either focus can run on either weekday — alternate them.

## Progression Guidelines

**Bench press (the gated lift)**
- Top of every working set: stop on first sign of hand twinge, regardless of reps left
- Clean session = 4×5 with no pain at any point AND last set still RPE ≤ 8
- Two consecutive clean sessions at a given weight → bump 2.5 kg next session
- One symptomatic session → hold the weight, add a 5th set, retry next session

**Bench load ladder for this block** (target — adjust by feel, not the calendar):
- Sessions 1–2: 45 kg × 4×5 (today's session was clean at this load)
- Sessions 3–4: 47.5 kg × 4×5
- Sessions 5–6: 50 kg × 4×5 (the threshold — be alert)
- Session 7: 52.5 kg × 4×5
- Session 8: **1RM test** (rep-out proxy at 60 kg if no spotter, true single if spotter)

**Squat / Deadlift / Accessory**
- Standard rule: hit all prescribed reps at RPE ≤ 8 → +2.5 kg next session
- Squat re-entry from deload: 47.5 → 50 → 52.5 → 55 → 57.5 over the block
- Dumbbells advance to next pair when current weight is clean (gym ladder is in 2.5 kg jumps)

**Deload**
- Not scheduled this block — deload was already taken in week 9
- If two consecutive sessions feel beat-up (poor sleep, achy joints, missed reps): cut volume by 50% for one session and proceed

## Notes

**Hand injury management**
- The cap is symptom-driven, not calendar-driven. The block could finish in 4 weeks or 8 — Tim's hand decides
- Watch incline DB press too — it's still a press and could provoke the same area. If 15 kg/hand twinges, drop to 12.5 and rebuild
- If symptoms persist past week 13, surface this in the next `/personal-trainer "feedback"` so we can substitute a press variant (e.g. floor press, neutral-grip DB press, machine press) that loads the hand differently

**Stop-skipping list**
Three lifts have been chronically dropped: Hip Thrust, Dumbbell Lunges, Face Pulls. Treat them as priority-2 — drop *Row* or *Trap Bar* before any of these three if time-pressed. Hip Thrust in particular is the main glute strengthener for the anterior pelvic tilt correction.

**Anterior pelvic tilt management**
- Couch stretches and glute bridges in every warm-up — don't skip
- Hip thrusts, hanging leg raises / dead bugs are the active correction. Couch stretch alone won't fix it

**Bench Press 1RM goal**
- Last known 1RM: 70 kg (Jan 2026)
- Pre-injury working weight was 52.5 kg × 4×5 in week 7 — that projects to ~61 kg estimated 1RM
- Once cleared, the rep-out at 60 kg should land in the 4–8 rep zone for a 68–76 kg projection. A true spotted 1RM after that would target the 70+ kg range

**Recovery at 50**
- 48+ hours between gym sessions remains the rule
- Endurance sports continue — keep them on non-gym days when possible
- 7–8 hours sleep, 1.6–2.0 g/kg protein (112–140 g daily)
